# AI and Human Messenger — страница чата

Репозиторий: `dperegudov61/AI-Human-Messenger`
Адрес: **https://dperegudov61.github.io/AI-Human-Messenger/**

Это постоянный адрес страницы чата. Адрес туннеля меняется при каждом перезапуске,
а страница — нет: она сама находит живой мост и работает с ним.

| файл | что это |
|---|---|
| `index.html` | страница чата |
| `404.html` | её копия: Pages отдаёт её на любой неизвестный путь (кладёт `publish_door.ps1`) |
| `.nojekyll` | отключает обработку Jekyll |

Публикация: правим `messenger\` в проекте → `.\publish_door.ps1` → через полминуты
страница обновится.

## Как она работает

1. **Мост.** Читает `status.json` репозитория `dperegudov61.github.io` (api.github.com →
   Pages → raw), проверяет кандидатов `GET /__door/hi`, свежие мосты — первыми,
   старше 60 минут — в хвост. Последний живой адрес помнит в `localStorage`.
2. **Вход.** Токен лежит в `door.token` — его кладёт страница `/accounts/` при входе
   (страницы на одном сайте `dperegudov61.github.io` видят общий `localStorage`).
   Если токена нет, но на устройстве сохранён быстрый ключ (`door.key`), страница сама
   меняет его на токен через `POST /__door/auth`. Совсем без входа — оверлей с кнопкой
   «Войти» (`/accounts/?next=<эта страница>`), после входа страница открывается снова.
3. **Запросы.** Абсолютный адрес моста + `Authorization: Bearer <токен>`.
   Картинки — `/i/<id>?v=small&tk=<токен>`: у `<img>` нет заголовков, поэтому токен в ссылке.
4. **Люди.** `GET /__people` — кто есть и кто на связи; клик — `POST /__pm/open`
   (личная переписка, один файл на двоих, третий не видит).
5. **Переписки.** `GET /__boot` → общий чат, личные, чаты с ИИ; «＋» создаёт новый чат с ИИ.
6. **Сообщения.** Людям — `POST /__msg`. ИИ — `POST /v1/chat/completions` (заголовок
   `X-Chat-Id`), затем сохранение через `POST /__log`.
7. **Картинки.** «＋» в строке ввода — загрузка (`POST /__img/upload`), в ленте показывается
   сжатая копия, клик открывает полную, 🔗 выдаёт ключ-ссылку (`POST /__img/share`).
   Чужие картинки сервер не отдаёт: адрес случайный, а права проверяются на сервере.
